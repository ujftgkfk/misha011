# TechStore - Интернет-магазин электроники

Современный, адаптивный сайт для продажи электроники и гаджетов.

## 🎯 Особенности

- ✅ Адаптивный дизайн (работает на всех устройствах)
- 🛒 Функциональная корзина покупок
- 💾 Сохранение корзины в localStorage
- 🎨 Современный и чистый UI
- 📱 4 страницы: Главная, Товары, Корзина, Контакты
- 🔍 Фильтрация и сортировка товаров
- 📦 12 товаров в каталоге

## 📁 Структура проекта

```
/
├── index.html          # Главная страница
├── products.html       # Страница каталога товаров
├── cart.html          # Страница корзины
├── contact.html       # Страница контактов
├── css/
│   └── style.css      # Все стили сайта
├── js/
│   ├── products.js    # База товаров и управление каталогом
│   ├── cart.js        # Функционал корзины
│   └── main.js        # Основные функции
└── images/            # Папка для изображений
```

## 🚀 Как запустить

1. Просто откройте файл `index.html` в браузере
2. Или используйте локальный сервер:
   ```bash
   # С помощью Python
   python -m http.server 8000

   # С помощью Node.js
   npx http-server
   ```

## 🛍️ Функционал

### Главная страница
- Приветственный баннер
- Популярные товары
- Преимущества магазина

### Страница товаров
- Полный каталог (12 товаров)
- Фильтрация по категориям
- Сортировка по цене и названию
- Быстрое добавление в корзину

### Корзина
- Просмотр добавленных товаров
- Изменение количества
- Удаление товаров
- Подсчет итоговой суммы
- Расчет стоимости доставки

### Контакты
- Информация о компании
- Контактные данные
- Форма обратной связи

## 🔧 Настройка

### Добавление новых товаров

Отредактируйте файл `js/products.js`:

```javascript
{
    id: 13,
    name: 'Название товара',
    category: 'smartphones', // smartphones, laptops, audio, accessories
    price: 99990,
    description: 'Описание товара',
    icon: '📱' // Emoji иконка
}
```

### Изменение стилей

Основные цвета и переменные находятся в начале `css/style.css`:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #10b981;
    /* и т.д. */
}
```
