## 📖 Описание

**SUCCESSION: Империя Власти** - это интерактивная стратегическая игра-симулятор жизни, основанная на популярном сериале "Succession". Погрузитесь в мир корпоративных интриг, семейных драм и борьбы за власть в медиаимперии Waystar Royco.

## 🚀 Как играть

### Запуск игры

1. **Простой способ** - откройте `index.html` в браузере
2. **С локальным сервером**:
   ```bash
   # Python 3
   python -m http.server 8000

   # Node.js (если установлен http-server)
   npx http-server
   ```
   Затем откройте http://localhost:8000

### Управление

1. **Начало игры:**
   - Выберите персонажа
   - Изучите его характеристики
   - Начните первый день

2. **Игровой процесс:**
   - Читайте события и делайте выборы
   - Следите за статистикой в левой панели
   - Управляйте отношениями с ключевыми персонажами
   - Отслеживайте новости о ваших действиях

3. **Сохранение:**
   - Игра автоматически сохраняется каждые 2 минуты
   - Можно сохранить вручную через меню
   - Загрузка доступна при следующем запуске

## 📊 Игровые характеристики

### Основные показатели

- **💼 Влияние (0-100)** - ваша власть в компании
- **⭐ Репутация (0-100)** - как вас воспринимают акционеры и публика
- **💰 Капитал ($)** - личное богатство в миллионах
- **❤️ Здоровье (0-100)** - физическое и психическое состояние

### Отношения

Отслеживаются с ключевыми персонажами:
- **Логан Рой** - отец и CEO
- **Братья/Сестры** - конкуренты за власть
- **Герри Келлман** - главный юрисконсульт
- **Стьюи Хоскенни** - враждебный инвестор
- И другие...

### Концовки

Игра имеет **4 возможные концовки**:

1. 🏆 **Победа: Новый CEO** - вы становитесь главой империи
2. 👔 **Успех: Место в совете** - важная, но не главная роль
3. 📊 **Сохранение статуса** - остаетесь на текущей позиции
4. 💔 **Поражение: Изгнание** - вас выгоняют из компании

Концовка зависит от:
- Уровня влияния
- Отношений с Логаном
- Репутации
- Ключевых решений в игре

## 🎯 Советы по прохождению

### Стратегии успеха

1. **Баланс власти и репутации**
   - Не жертвуйте репутацией ради краткосрочной выгоды
   - Публичный имидж важен для долгосрочного успеха

2. **Отношения с Логаном**
   - Это ключевой фактор для победы
   - Лояльность важна, но не будьте подхалимом

3. **Здоровье**
   - Не игнорируйте показатель здоровья
   - Низкое здоровье триггерит негативные события

4. **Финансы**
   - Инвестируйте разумно
   - Капитал дает независимость

5. **Семейные отношения**
   - Альянсы с братьями/сестрами могут быть полезны
   - Но в финале каждый за себя

## 🔧 Разработка

### Добавление новых событий

События находятся в `events.js`:

```javascript
{
    id: 'unique_id',
    week: 1,
    title: 'Название события',
    description: 'Описание...',
    choices: [
        {
            text: 'Вариант выбора',
            effects: {
                influence: 5,
                logan: 3
            },
            news: 'Текст новости'
        }
    ]
}
```

### Добавление персонажей

Новые NPC добавляются в `characters.js`:

```javascript
new_character: {
    id: 'new_character',
    name: 'Имя Персонажа',
    position: 'Должность',
    description: 'Описание',
    influence: 50,
    relationship: 50
}
```
