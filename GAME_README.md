# 🎬 Media Mogul: The Warner Bros. War

## Описание игры

**Media Mogul** - это стратегическая бизнес-симуляция, основанная на реальных событиях борьбы за покупку Warner Bros. Discovery в 2025 году. Вы играете за одну из трех компаний (Paramount Skydance, Netflix или Comcast), пытаясь выиграть аукцион на покупку медиа-гиганта.

### Основные механики:

- 💰 **Управление ресурсами** - Наличные деньги, долговое финансирование, политический капитал, репутация
- 🤝 **Переговоры** - Встречи с ключевыми фигурами (CEO, президент, регуляторы)
- 📊 **Торги** - Конкурентные раунды предложений
- 🏛️ **Политика** - Лоббирование в Вашингтоне, работа с Трампом
- 👔 **Акционеры** - Убеждение институциональных инвесторов

## Установка и запуск

### Вариант 1: Локальный запуск

1. Скачайте все файлы проекта
2. Откройте файл `index.html` в современном браузере (Chrome, Firefox, Edge)
3. Игра готова к запуску!

### Вариант 2: Веб-сервер

Для лучшей производительности рекомендуется запускать через локальный веб-сервер:

```bash
# Python 3
python -m http.server 8000

# или Python 2
python -m SimpleHTTPServer 8000

# или Node.js
npx http-server -p 8000
```

Затем откройте браузер и перейдите на `http://localhost:8000`

## Как играть

### Цель игры

Выиграть аукцион на покупку Warner Bros. Discovery, сделав лучшее предложение и получив одобрение:
- Совета директоров WBD
- Акционеров (>50%)
- Регуляторов (DOJ/FTC)

### Условия победы

1. **Ваша ставка ≥ $35/акцию**
2. **Отношения с Zaslav ≥ 70/100**
3. **Антимонопольное давление < 50**
4. **Поддержка акционеров > 50%**

### Условия поражения

- ⏰ **Время истекло** (120 дней)
- 💸 **Банкротство** (cash < -10B)
- ⚖️ **Блокировка регуляторами** (antitrust > 50)
- 🏢 **Конкурент выиграл**

### Игровой процесс

#### День за днём

Каждый игровой день вы можете:

1. **Negotiate** - Встретиться с ключевыми людьми
   - David Zaslav (CEO WBD) - главный судья
   - Donald Trump (President) - политическая поддержка
   - Регуляторы (DOJ/FTC) - антимонопольное одобрение

2. **Finance** - Управление финансами
   - Поднять ставку
   - Привлечь финансирование
   - Использовать долг или акции

3. **Politics** - Политические действия
   - Лоббировать DOJ/FTC
   - Позвонить Трампу
   - Запустить медиа-кампанию
   - Встречи с акционерами

4. **Shareholders** - Работа с акционерами
   - Презентации для Vanguard, BlackRock
   - Roadshow для инвесторов

5. **Next Day** - Перейти к следующему дню

#### Ресурсы

- 💰 **Cash** - Наличные деньги для ставок и действий
- 🏛️ **Political Influence** (0-100) - Для политических действий
- ⭐ **Reputation** (0-100) - Влияет на отношения и доверие
- 📊 **Stock** - Стоимость акций (для Netflix)

#### Отношения (0-100)

- **David Zaslav** - Самый важный! Его решение финальное
- **Donald Trump** - Может помочь с регуляторами
- **Jonathan Kanter** (DOJ) - Антимонопольный контроль
- **Lina Khan** (FTC) - Защита конкуренции
- **Larry Ellison** - Ваш отец (если Paramount)

#### События

Случайные события происходят каждый день:

**Положительные:**
- Ужин в Mar-a-Lago с Трампом (+50 influence)
- Положительная статья в WSJ (+20 reputation)
- Поддержка крупного акционера (+15% голосов)

**Отрицательные:**
- Гильдия режиссёров против сделки (-30 reputation)
- Утечка информации (-25 influence)
- Антимонопольный иск (-3 месяца delay)
- Критика Трампа в Truth Social (-40 influence)

### Раунды торгов

**Round 1** - Day 80 (November 20)
- Первые официальные предложения
- Min: $25/share

**Round 2** - Day 91 (December 1)
- "Best and final"
- Min: $28/share

**Round 3** - Day 94 (December 4)
- Финальный раунд
- Min: $30/share

### Стратегии

#### Агрессивная стратегия
- Сразу большая ставка ($32+)
- Активное лоббирование
- Риск: быстро тратите ресурсы

#### Дипломатическая стратегия
- Фокус на отношениях с Zaslav
- Работа с акционерами
- Меньший риск, но медленнее

#### Политическая стратегия
- Использование связей с Трампом
- Работа с регуляторами заранее
- Требует высокого influence

#### Враждебное поглощение
- Если не можете договориться с советом
- Идёте напрямую к акционерам
- Нужно 50%+ поддержки акционеров
- Сильно вредит репутации

## Клавиатурные сокращения

- **Space/Enter** - Следующий день
- **1** - Negotiate
- **2** - Finance
- **3** - Politics
- **4** - Shareholders
- **Esc** - Закрыть модальное окно
- **Ctrl+S** - Сохранить игру вручную

## Debug команды

Откройте консоль браузера (F12) и используйте:

```javascript
// Посмотреть состояние игры
DEBUG.showState()

// Добавить ресурсы
DEBUG.addCash(10)        // Добавить $10B
DEBUG.addInfluence(20)   // Добавить 20 influence
DEBUG.addReputation(30)  // Добавить 30 reputation

// Изменить отношения
DEBUG.setRelationship('zaslav', 80)
DEBUG.setRelationship('trump', 90)

// Перепрыгнуть на день
DEBUG.jumpToDay(80)

// Запустить событие
DEBUG.triggerEvent('trump_dinner')

// Список всех событий
DEBUG.listEvents()

// Мгновенная победа
DEBUG.win()

// Сбросить игру
DEBUG.reset()
```

## Сохранение игры

Игра автоматически сохраняется:
- Каждую минуту (авто-сохранение)
- После каждого хода
- При закрытии браузера

Сохранение хранится в localStorage браузера.

## Советы для победы

1. **Следите за конкурентами** - Netflix будет поднимать ставку
2. **Стройте отношения рано** - Zaslav - ключ к победе
3. **Баланс ресурсов** - Не тратьте всё на одно
4. **Используйте Трампа** - Но осторожно, может обернуться против вас
5. **Антимонопольные риски** - Держите под контролем
6. **Акционеры важны** - Особенно для враждебного поглощения

## FAQ

**Q: Можно ли сыграть за Netflix или Comcast?**
A: В текущей версии только Paramount. Другие фракции будут добавлены в обновлениях.

**Q: Реально ли выиграть?**
A: Да! Есть несколько путей к победе. Попробуйте разные стратегии.

**Q: Почему Трамп так важен?**
A: В реальности у David Ellison есть связи с Трампом через отца. Это даёт политические преимущества.

**Q: Что значит "враждебное поглощение"?**
A: Это когда вы обходите совет директоров и идёте прямо к акционерам. Рискованно, но может сработать.

**Q: Сколько времени займёт одна игра?**
A: От 30 минут до 2 часов, в зависимости от стратегии.
