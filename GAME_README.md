# Political Strategy Game

Пошаговая политическая стратегическая игра, где вы управляете политической партией, участвуете в выборах и принимаете важные решения.

## Особенности игры

- **Управление партией**: Создайте свою политическую партию и выберите идеологию
- **Пошаговая стратегия**: Принимайте решения каждый квартал
- **Выборы**: Участвуйте в выборах каждые 4 года
- **Случайные события**: Реагируйте на кризисы и возможности
- **Экономика**: Управляйте бюджетом партии
- **Репутация**: Поддерживайте общественную поддержку и репутацию
- **ИИ противники**: Соперничайте с 4 партиями, управляемыми ИИ

## Как играть

### Создание партии

1. Запустите игру и нажмите "New Game"
2. Выберите идеологию для своей партии:
   - **Liberal** (Либеральная) - синий цвет
   - **Conservative** (Консервативная) - красный цвет
   - **Progressive** (Прогрессивная) - зеленый цвет
   - **Centrist** (Центристская) - фиолетовый цвет
   - **Nationalist** (Националистическая) - оранжевый цвет

3. Нажмите "Start Game"

### Игровой процесс

#### Основные показатели

- **Public Support (Общественная поддержка)**: Процент населения, поддерживающего вашу партию (0-100%)
- **Reputation (Репутация)**: Общественное мнение о вашей партии (0-100)
- **Funds (Средства)**: Деньги партии для проведения кампаний и мероприятий
- **Parliament Seats (Места в парламенте)**: Количество мест в парламенте (из 100)

#### Действия

Каждый ход вы можете выполнить следующие действия:

1. **Campaign (Кампания)** - Стоимость: $15,000
   - Запускает рекламную кампанию
   - Увеличивает общественную поддержку на 1.5-4%
   - Лучший способ повысить популярность перед выборами

2. **Policy (Политика)** - Стоимость: $5,000
   - Предложение новой политики
   - Немного увеличивает поддержку и репутацию
   - Более дешевый вариант для улучшения имиджа

3. **Fundraise (Сбор средств)** - Бесплатно
   - Проведение мероприятия по сбору средств
   - Получите $5,000-$20,000
   - Может слегка повлиять на репутацию

4. **End Turn (Закончить ход)** - Бесплатно
   - Завершает текущий квартал
   - Переходит к следующему ходу
   - Может вызвать случайное событие

### Случайные события

С шансом 30% каждый ход может произойти случайное событие:
- **Экономические кризисы**
- **Скандалы**
- **Социальные движения**
- **Международные кризисы**
- **Дебаты о реформах**
- **Предложения от доноров**
- **Экологические катастрофы**

Каждое событие предлагает 3 варианта выбора с различными последствиями.

### Выборы

Выборы проходят каждые 4 года (каждые 16 ходов).

**Как победить в выборах:**
- Набрать наибольшее количество голосов
- Получить большинство мест в парламенте
- Конкурировать с 4 партиями ИИ

**После выборов:**
- Распределяются места в парламенте
- Партия-победитель получает власть
- Продолжается игровой процесс

### Советы для успеха

1. **Балансируйте бюджет**: Не тратьте все деньги сразу
2. **Следите за поддержкой**: Старайтесь держать поддержку выше 25%
3. **Готовьтесь к выборам**: Проводите больше кампаний за несколько ходов до выборов
4. **Думайте о последствиях**: Каждое решение влияет на поддержку, репутацию или средства
5. **Используйте события**: Случайные события могут дать преимущество, если выбрать правильный вариант

## Возможности для расширения

Игра построена модульно и может быть легко расширена:

- Добавление новых событий в `src/systems/events.py`
- Создание новых идеологий в `src/core/constants.py`
- Добавление новых действий в `src/ui/screens.py` (GameScreen)
- Улучшение ИИ в `src/core/party.py` (AIParty)
