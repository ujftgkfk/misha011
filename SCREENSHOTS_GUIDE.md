## 5. 📊 Детали интерфейса

### Цветовая схема:
```css
Основные цвета:
- Темный фон: #0a0e27 → #1a1f3a (градиент)
- Вторичный фон: #1a1f3a (80% opacity)
- Золотой акцент: #c9a961
- Темное золото: #a88b47
- Текст основной: #ffffff
- Текст вторичный: #b8b8b8
- Границы: #2a2f4a
```

### Типографика:
```css
Заголовки: 'Playfair Display', serif
  - Главный: 5rem, 900 weight
  - H2: 3rem
  - H3: 2.2rem

Основной текст: 'Inter', sans-serif
  - Обычный: 1rem, 400 weight
  - Жирный: 600-700 weight
  - Кнопки: 1.1rem, 600 weight
```

### Анимации:
- **Появление:** fadeInUp (1s ease)
- **Ховер кнопок:** translateY(-2px) + увеличение тени
- **Выбор:** opacity transition + border color
- **Фон:** bgPulse (20s infinite)

- Sidebar: 100% width, сверху

## 🎮 Как сделать скриншоты

### Для документации:

1. **Запустить игру:**
   ```bash
   python3 -m http.server 8080
   ```
   Открыть http://localhost:8080/index.html

2. **Скриншоты для каждого экрана:**
   - Intro screen (F12 → Screenshot)
   - Character select
   - Main game screen (начало)
   - Event example 1 (неделя 1)
   - Event example 2 (кризис)
   - Stats panel (боковая панель)
   - News feed
   - End game screen

3. **Сохранить в папку:**
   ```
   screenshots/
   ├── 01_intro.png
   ├── 02_character_select.png
   ├── 03_game_main.png
   ├── 04_event_board_meeting.png
   ├── 05_event_crisis.png
   ├── 06_stats_panel.png
   ├── 07_news_feed.png
   └── 08_game_end.png
   ```
