# 🛍️ Интернет-магазин

Современный интернет-магазин с корзиной покупок, фильтрацией товаров и адаптивным дизайном.

## ✨ Функциональность

### 🛒 Корзина покупок
- Добавление товаров в корзину
- Изменение количества товаров
- Удаление товаров из корзины
- Автоматический подсчет итоговой суммы
- Сохранение корзины в localStorage

### 🔍 Поиск и фильтрация
- Полнотекстовый поиск по названию и описанию товаров
- Фильтрация по категориям:
  - Электроника
  - Одежда
  - Книги
  - Для дома
- Фильтрация по диапазону цен

### 📊 Сортировка
- По цене (возрастание/убывание)
- По названию (А-Я/Я-А)
- По умолчанию

### 🎨 Дизайн
- Современный градиентный дизайн
- Адаптивная верстка для мобильных устройств
- Анимации и плавные переходы
- Модальное окно корзины

## 🚀 Запуск проекта

### Вариант 1: Простой запуск
Откройте файл `shop.html` в браузере напрямую.

### Вариант 2: Локальный сервер

1. Установите http-server (если не установлен):
```bash
npm install -g http-server
```

2. Запустите сервер:
```bash
npm start
# или
http-server -p 8080
```

3. Откройте в браузере:
```
http://localhost:8080/shop.html
```

## 📝 Использование

### Добавление товаров
1. Просмотрите каталог товаров на главной странице
2. Нажмите кнопку "В корзину" под нужным товаром
3. Товар добавится в корзину с уведомлением

### Управление корзиной
1. Нажмите на иконку корзины в шапке сайта
2. В открывшемся окне вы можете:
   - Изменить количество товаров кнопками +/-
   - Удалить товар кнопкой "Удалить"
   - Очистить всю корзину кнопкой "Очистить корзину"
   - Оформить заказ кнопкой "Оформить заказ"

### Фильтрация и поиск
1. Используйте строку поиска для быстрого нахождения товаров
2. Выберите категории в боковой панели
3. Установите диапазон цен
4. Выберите нужную сортировку

## 🔧 Настройка

### Добавление новых товаров

Откройте файл `js/app.js` и добавьте новый товар в массив `products`:

```javascript
{
    id: 13,
    name: "Название товара",
    category: "electronics", // electronics, clothing, books, home
    price: 10000,
    description: "Описание товара",
    icon: "📱" // Emoji иконка
}
```

### Изменение цветовой схемы

Откройте файл `css/style.css` и измените градиент в стилях header:

```css
header {
    background: linear-gradient(135deg, #your-color1 0%, #your-color2 100%);
}
```
