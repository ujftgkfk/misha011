# Быстрый старт

## Установка и запуск за 3 шага

### 1. Установите зависимости
```bash
pip install pygame
```

### 2. Запустите игру
```bash
python main.py
```

### 3. Начните играть
- Нажмите "New Game"
- Выберите идеологию
- Нажмите "Start Game"

## Основные действия

| Действие | Стоимость | Эффект |
|----------|-----------|--------|
| Campaign | $15,000 | +1.5-4% поддержки |
| Policy | $5,000 | +поддержка, +репутация |
| Fundraise | Бесплатно | +$5,000-$20,000 |
| End Turn | Бесплатно | Следующий ход |

## Цель игры

Победить на выборах через 16 ходов (4 года)!

## Советы

- Держите поддержку > 25%
- Сохраняйте средства для кампаний
- Выбирайте мудро в событиях
- Проводите кампании перед выборами

Удачи!
